## ⚙️ How to Compile & Run

Make sure you have **g++** installed (C++17 or later recommended).
```bash
# Compile
g++ -std=c++17 -o solution filename.cpp

# Run
./solution
```

**On Windows (MinGW):**
```bash
g++ -std=c++17 -o solution.exe filename.cpp
solution.exe
```
